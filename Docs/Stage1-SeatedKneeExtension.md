# 第1段：坐位膝伸技术验证

本段仅验证四传感器角度、准备/伸膝/保持/返回及完整动作计数。

## 运行

1. 打开 `Assets/City park/Scenes/RehabPhotoGame.unity`。若还没有生成，在 Unity 菜单选择 `Tools > Rehab Photo Game > Open Stage 1 - Seated Knee Extension`，它会复制 SampleScene 并添加验证组件；已有目标场景不会被覆盖。
2. 进入 Play，按现有动捕流程连接串口。佩戴 06 左大腿、07 左小腿、08 右大腿、09 右小腿；先站姿完成四传感器统一标定和开始驱动，再坐下。不要在坐位重新标定零位。
3. 右上角技术面板选择左腿、右腿或双腿。默认左腿；选择单腿也要求四传感器在线。切换选择会重置本项计数。
4. 坐位准备：双侧大腿角在 55～120°，所选膝角在 70～110°，稳定约 0.6 秒。
5. 缓慢伸膝：所选膝角进入 ≤20°。持续稳定 3 秒后转入“返回”；进入保持后允许 5°的边缘余量，超过 25°重新伸膝。窗口内膝角或大腿角的波动超过 5°会重新计时。
6. 放回小腿，在准备范围稳定约 0.6 秒，次数才 +1；一直伸直或一直放下都不会重复计数。

以上是可在 `Seated Knee Extension - Stage 1` 对象 Inspector 中修改的联调初值，不是医学测量标准或训练处方。不做正式 UI、摄影素材、坐站、浅蹲或训练阶段解锁。

## 角度与数据有效性

- 0°表示膝伸直，约90°表示坐位弯曲。基于当前客户算法的四元数坐标映射、站姿标定及左右符号约定，输出矢状面内的估计角度。
- 游戏读取显示增益和限幅之前的测量。左腿现有显示增益可能将实际输入30°画成0°，因此技术面板角度可能与人物外观不同；不要用人物已伸直代替达到游戏目标。
- 游戏不读取右腿长期保持值或另一条腿的镜像回退值。原有动捕骨骼驱动行为保持原样。
- 按当前实时时钟检查四设备最后真实出队时间；默认任一设备超过1.5秒无新帧即中止未完成动作。设备间最后收帧时间差超过1秒也中止。
- 保持时长只在四设备的最旧收帧时间向前推进时累计，Unity重复渲染旧帧不计时。全部断流也会被识别，恢复后必须重新准备，已完成次数保留。
- 无效四元数、退化投影、未标定、未驱动、断开、重新标定、离开坐位均不能完成动作。

## 文件日志

既有 `Logs/motion_diagnostic_*.jsonl` 继续工作，新增 `event` 记录的名称以 `knee_extension_` 开头：配置、状态变化、每0.5秒的测量快照、重置和禁用。`detail` 是 JSON 字符串，包含左右实测膝/大腿角、采样时刻、四设备新鲜度位掩码、标定版本、阶段、保持秒数和次数。诊断记录不显示在游戏面板，也不刷屏输出到 Console。

## 验收

- 正常完整动作连续做3次，恰好计3次。
- 直接伸直但未先准备，不计数；保持不足3秒就放下，不计数。
- 达标后一直伸直不反复计数；放回才完成本次。
- 目标边缘轻微变化不会来回跳阶段，大幅晃动重新计时。
- 左/右/双腿选择正确；站姿膝伸不能冒充坐位动作。
- 保持中关闭09，以及四设备同时停更：计时停止，恢复后不能补计中断动作。
- 重新标定、切换训练腿、重置计数都不能续接旧保持进度。
