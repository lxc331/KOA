# 第2段：S1 正式训练界面

## 已实现

- 运行时创建 Canvas + TextMeshPro 正式训练界面；
- 使用随项目分发的 `NotoSansSC-Regular.ttf` 动态中文字体，不依赖客户电脑的系统字体；
- Windows 下优先使用微软雅黑动态字体，避免中文显示为方框；
- 目标次数可在 1～20 次之间调整，默认 3 次；
- 开始、暂停、继续、结束和重新训练；
- 左腿 `06+07`、右腿 `08+09` 手动选择，同时保留原自动跟随活动腿；
- 远景模糊到清晰、保持进度、快门闪光和运行时快门音效；
- 每次成功拍摄显示单次结果卡；
- 完成目标后显示本组总结；
- 断流时冻结训练，暂停或结束后不继续累计；
- 正式界面只显示连接状态、设备编号、动作提示和游戏进度，不显示四元数、欧拉角、串口帧或诊断中间量。

## 运行步骤

1. 打开 `Assets/City park/Scenes/RehabPhotoGame.unity` 并进入 Play。
2. 点击右上角“设备设置”，选择串口并连接四个传感器。
3. 保持站姿完成标定并开始动捕；准备完成后设备设置窗口会自动隐藏。
4. 坐下，让小腿自然下垂。
5. 在开始卡片上设置目标次数并点击“开始训练”。
6. 选择左腿或右腿，缓慢伸膝；照片完全清晰后保持 3 秒。
7. 听到快门声并看到结果卡后缓慢放下小腿，再进行下一次。

## 本段验收

- 进入 Play 后能看到正式白绿 Canvas 界面，旧底部 IMGUI 训练面板和右上四元数表不显示；
- 中文显示正常，按钮可以点击；
- 未连接或未开始动捕时，“开始训练”不可用；
- 目标次数加减范围正确；
- 暂停后保持时间和快门不继续，继续时要求重新自然下垂准备；
- 每次完整保持只有一次声音、闪光和结果卡；
- 达到目标次数后自动进入完成卡，不再累计；
- 点击结束后显示本次完成数量；
- `Logs/motion_diagnostic_*.jsonl` 中存在 `s1_session_*` 和 `photo_capture` 事件。

本段没有新增坐站、浅蹲、多图片相册或训练历史。
