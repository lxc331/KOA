# 第3段：坐站摄影动作说明

## 完成范围

- 新增独立的坐站状态机和可序列化参数配置；
- 正式中文界面新增“坐站摄影”模式，并保留原有“坐姿伸膝”；
- 双腿协同伸直时，取左右腿中较慢一侧作为取景框升高进度；
- 取景框位置固定，图片内容在裁切视口内随进度上下滚动；
- 站稳保持 2 秒后触发一次快门，稳定坐回后才允许下一次；
- 接入 3 张 `B_高处` 照片，按完成次数轮换；
- 复用 `MotionCaptureController` 的 06～09 采样、帧龄健康状态、人物驱动、根节点补偿和 JSONL 日志。

## 状态机

| 状态 | 进入条件 | 退出条件 | 界面表现 |
| --- | --- | --- | --- |
| `Preparing` | 开始、重置或一轮完成 | 坐姿稳定 0.7 秒 | 提示双脚着地并坐稳 |
| `Rising` | 坐姿参考建立 | 四个角度达到站姿阈值 | 双腿协同伸直，取景框升高 |
| `Holding` | 双腿达到站姿 | 稳定 2 秒或离开站姿 | 保持计时并准备快门 |
| `Returning` | 快门完成 | 回到本轮坐姿参考并稳定 0.6 秒 | 要求缓慢坐回 |

进度不是左右平均值，而是：

1. 每条腿分别取“大腿伸直进度”和“膝伸直进度”的较小值；
2. 总进度再取左右腿的较小值。

因此只有小腿前踢、只有一侧站起或左右动作差过大时，取景框都不能升到完成位置。

## 取景框表现

高处图片不再随人物站起而整体向上移动。界面创建一个固定尺寸的 `Photo Viewport`，内部图片内容放大少量并由 `RectMask2D` 裁切；坐站进度只改变内容的垂直偏移，取景框边界、标题和下方提示始终保持不动。这样用户看到的是“镜头向上寻找高处目标”，而不是整个图片面板被抬高。

## 动作模式隔离

进入坐站摄影时会关闭坐姿伸膝运行时，清除 S1 的坐姿腿校正和视觉保持，恢复双脚共同贴地并启用根节点补偿。切回坐姿伸膝后，由 S1 重新建立坐姿映射。两个状态机不会同时写人物姿态。

## 信号和日志

坐站模式要求 06、07、08、09 四个传感器全部有效。短时断流冻结当前阶段、取景高度和保持计时；中断超过 4 秒时取消本轮，恢复后必须重新坐稳。重复的旧时间戳不能累计稳定时间，重标定版本变化会清除旧坐姿参考。

结构化日志统一通过 `MotionCaptureController.LogTrainingDiagnostic` 写入，坐站事件使用 `sit_to_stand_` 前缀；原伸膝日志继续保留 `knee_extension_` 前缀。

## 默认参数

| 参数 | 默认值 |
| --- | ---: |
| 坐姿大腿范围 | 60°～135° |
| 坐姿膝角范围 | 55°～145° |
| 站姿大腿上限 | 35° |
| 站姿膝角上限 | 30° |
| 左右进度最大差 | 0.30 |
| 坐姿确认 | 0.7 秒 |
| 站姿保持 | 2.0 秒 |
| 坐回确认 | 0.6 秒 |
| 传感器新鲜度 | 2.2 秒 |
| 断流宽限 | 4.0 秒 |

这些参数是游戏联调默认值，不是医学处方。客户现场验收时应根据椅高、佩戴方向和患者活动范围调节。

## 验收重点

1. 坐稳后双腿同步站起，取景框连续升高并只拍一张；
2. 保持站立不重复拍摄，坐回后才可进入下一次；
3. 任意单腿前踢不会抬高总进度、不会触发快门；
4. 任意一个 06～09 传感器短时掉线会冻结而不是补算；
5. 长断流、重标定或旧样本不能承接上一轮动作；
6. 切换回坐姿伸膝后，第一、二段原有流程仍正常。
