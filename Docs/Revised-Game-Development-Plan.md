# 《公园摄影站》客户新版基线与分段制作计划

更新日期：2026-09-13

## 当前已经完成

客户回传的 V2026.09.06-35c08c0 已作为新基线合入：

- 四传感器 06～09 的 Unity 通信、标定与人物驱动；
- 坐姿伸膝的准备、抬腿、保持、放下四阶段；
- 左右腿独立判定、手动切腿和自动跟随活动腿；
- 右腿自然下垂膝角、坐姿大腿角的会话校正；
- 相对准备角度的伸膝目标，而不是要求绝对伸直到 0°；
- 3 秒保持、迟滞、稳定窗口、短时断流暂停和长时断流取消；
- 次数、膝角、保持时间、语音提示和白绿训练面板；
- 全局重置、重置次数和诊断 JSONL 日志。

因此原计划的“坐位膝伸技术验证”已经基本完成。后续从摄影玩法开始，不再建立第二套动作算法。

## 新分段计划

### 第1段：坐位伸膝摄影闭环（本次）

- 只导入一张 `A_远景` 照片；
- 直接读取客户版训练快照，伸膝进度控制模糊到清晰；
- 达标保持完成时触发一次快门闪光和成功提示；
- 切腿、重置、断流时不串接旧动作或误拍；
- `photo_capture` 只写入 JSONL 诊断日志，不显示四元数等调试参数。

验收：左右腿各完成 2 次，画面能连续对焦，每个完整保持只拍 1 张；断流、切腿、未准备直接伸腿均不能误拍。

### 第2段：S1 正式训练界面（本次已完成）

- 将技术验证 IMGUI 迁移为 Canvas + TextMeshPro；
- 加入开始、暂停、继续、结束、目标次数和单次结果卡；
- 加入快门音效、教练示范占位和适合患者观看的提示；
- 四元数、串口帧及诊断中间量仍不进入正式 UI。

实现结果：运行 `RehabPhotoGame` 场景时自动创建 Canvas + TextMeshPro 正式界面；训练前显示必要的设备连接窗口，开始动捕后隐藏旧四元数遥测表。界面已具备目标次数、开始、暂停、继续、结束、左右腿选择、患者提示、快门声和单次结果卡。

### 第3段：坐站摄影动作（本次已完成）

- 新建坐站状态机和参数配置；
- 双腿协同伸直驱动取景框升高；
- 接入少量 `B_高处` 素材；
- 与现有伸膝动作共享传感器健康和日志接口。

实现结果：正式摄影界面的训练设置中增加“坐姿伸膝 / 坐站摄影”模式切换；坐站模式要求先稳定坐姿、再由左右大腿与小腿共同伸直，使固定取景框内的高处图片内容随双腿较慢一侧的进度向上滚动。站稳保持后只拍摄一次，必须稳定坐回后才能开始下一次。单腿前踢、单侧掉线、重复旧样本、重标定及长时间断流均不能完成拍摄。已从 `B_高处` 导入建筑远山、树梢鸟类、花灯灯笼各一张，并复用 06～09 实时健康状态与结构化 JSONL 日志。

### 第4段：浅蹲摄影动作（游戏联调版，待现场验收）

- 新建浅蹲状态机和参数配置；
- 双腿同步屈曲驱动取景框降低；
- 接入少量 `C_低处` 素材；
- 先打通游戏闭环；待客户稳定动作测量后，再收紧验证浅蹲、坐下和坐站的区分。

实现结果：正式摄影界面新增“浅蹲摄影”模式，并与坐姿伸膝、坐站运行时互斥。取景框固定，`C_低处` 图片内容随双腿进度向上滚动，形成镜头降低的效果。保持 2 秒触发一次快门，稳定站回后才完成循环。

2026-09-13 游戏联调调整：保留稳定站姿前置，以双膝相对各自站姿参考的屈曲量为主进度（默认各 20°）；大腿最小变化改为辅助提示，普通左右差异不再阻止保持，明显单腿仍阻止拍摄。过深时进入独立调整状态、停止并清零保持，但保留站姿参考，回浅后重新保持；长时断流或重置仍需重新准备。新增可保存的 `ShallowSquatGameTuning` 配置资产及诊断字段。本轮不修改人物骨骼驱动、四元数转换和根节点补偿。

验收边界：此版优先验证“站稳 → 下蹲 → 保持拍照 → 站回”，不能据此认定“浅蹲与坐下已可靠区分”。真实动作测量由客户结合设备继续调整，动作区分留待后续收紧验证。调参及复测说明见 `Docs/Stage4-Shallow-Squat-Photography.md`。

### 第5段：训练流程与安全分支

- 四传感器检查、站姿标定引导和训练准备；
- 暂停、继续、安全停止、异常冻结；
- 单次训练总结与结构化结果日志；
- 不宣称四腿传感器能够识别躯干代偿、疼痛或真实跌倒。

### 第6段：S2 组合摄影

- 组合 A：坐姿伸膝对焦 → 放下 → 坐站拍高处；
- 组合 B：站立 → 浅蹲拍低处 → 返回站立；
- 加入步骤顺序、失败回退和组合照片。

### 第7段：S3 完整任务

- 串联坐位准备、伸膝、坐站、浅蹲、站立、坐回六个环节；
- 默认精简提示，按需显示帮助；
- 生成远景、高处、低处三联照片。

### 第8段：素材库与历史

- 每类先筛选 3～6 张并统一为真实 `.jpg`；
- 再评估 Addressables 导入全部素材；
- 增加训练历史、相册、阶段解锁和报告导出。

## 当前素材规则

原素材多数是 JPEG 内容但使用 `.png` 扩展名。项目复制后统一使用真实 `.jpg` 扩展名，并关闭 Read/Write 和 Mipmap。当前已导入 `A_远景/春/01.png`，`B_高处` 的建筑远山、树梢鸟类、花灯灯笼各一张，以及 `C_低处` 的草丛蘑菇、蝴蝶昆虫、荷花池各一张。空文件 `C_低处/草丛小景/02.png` 不得导入。
